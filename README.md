# Gymbro — Мобильное приложение для тренировок в зале (Билд 1.0)

Персональный дневник тренировок с таймером в реальном времени, календарём посещений, справочником упражнений с анатомической картой мышц, статистикой и личными рекордами.

## Как собрать и скачать APK на телефон через GitHub

1. Создайте новый репозиторий на **GitHub** (например, `Gymbro`).
2. Загрузите все файлы и папки из этого архива (`.github`, `app`, `build.gradle`, `gradle.properties`, `settings.gradle`, `README.md`) в репозиторий.
3. Перейдите во вкладку **Actions** вашего репозитория на GitHub — сборка запустится автоматически.
4. Дождитесь зелёной галочки у workflow **Build Gymbro APK** (~1 минута).
5. Откройте завершённую сборку, пролистайте вниз до раздела **Artifacts** и скачайте **`Gymbro-Build-1.0-APK`** на телефон.
6. Распакуйте архив на смартфоне и установите **`Gymbro-Build-1.0.apk`**.
